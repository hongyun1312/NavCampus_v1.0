
# 3DHub 前端网页样式风格详细总结

## 整体设计哲学与视觉基调

3DHub 的前端界面设计深受中国主流内容社区（尤其以 Bilibili 为典型参照）的设计语言影响，整体呈现出一种年轻化、活力感与亲和力并存的视觉气质。全站以粉红色系作为品牌核心主色调，但并非大面积铺陈，而是以点缀和强调的方式出现在关键交互节点上——按钮、选中态、链接、分隔线渐变等位置，形成“大面积留白基底 + 少量品牌色高亮”的克制型配色策略。页面背景统一使用浅灰调（#f5f5f7），与纯白卡片形成微妙的层次递进，营造出干净、清爽、适合长时间浏览的阅读氛围。这种设计风格在中文互联网语境下属于典型的“清新社区风”，优先考虑的是内容的可读性与用户的沉浸感。

整体布局采用经典的“固定顶栏 + 可滚动主体内容”结构，顶部导航栏高度为 64 像素，始终固定在视口最上方，带有极浅的投影（0 1px 2px rgba(0,0,0,0.06)），在不打扰内容的前提下提供清晰的页面层级感。主体内容区域在其下方自然流动，对于不需要完整导航栏功能的全屏页面（如地图发现模式、模型详情页）则通过 `margin-top: 64px` 配合 `height: calc(100vh - 64px)` 的方式充分利用剩余视口空间。整体没有采用暗色模式，所有页面均为浅色主题，唯一例外是模型详情页右侧的 3D 预览面板使用了深色背景（#1a1a2e），以更好地衬托 Three.js 渲染的三维模型内容。

## 品牌色彩体系

整个网站的色彩系统高度集中且一致。品牌主色为 `#fb7299`——一种柔和但不失活力的粉红色，接近 Bilibili 的标志色，具备极高的品牌辨识度。在需要层次变化的场景中，通过明度阶梯衍生出一套完整的色板：浅色变体 `#fc9bb9`（light-3）用于次级强调，`#fcd0df`（light-5）用于边框和浅色背景装饰，`#fde8ef`（light-7）和 `#fef4f7`（light-9）用于信息提示卡片和极浅底色；深色变体 `#f25d8e`（dark-2）作为悬停态的按钮背景色，`#e8517c` 则用于按下/激活态的进一步加深。

在文字颜色方面，系统采用了一套从深到浅的灰度层级：最深色 `#18191c` 用于标题和主要正文内容，确保高对比度的可读性；次要正文使用 `#303133`；辅助说明文字使用 `#606266` 和 `#61666d`；时间戳、次要统计等弱化信息使用 `#9499a0` 和 `#909399`；最弱的占位符和禁用态使用 `#B0B3BA` 和 `#c0c4cc`。这套文字色阶严格遵循“信息层级越重要，颜色越深越接近纯黑；越次要，颜色越浅越接近灰色”的原则，与 Material Design 的文本层级理念一致，但色值更贴合中文社区用户的阅读习惯。

功能性色彩方面，成功状态统一使用 Element Plus 默认的 `#67C23A` 绿色，警告状态使用 `#E6A23C` 橙色，与品牌粉色形成清晰的语义区分。建筑信息卡片使用品牌色的极浅渐变背景 `linear-gradient(135deg, #fef4f7, #fde8ef)` 搭配虚线分隔边框 `#fcd0df`，在白色内容区域中提供温和的视觉提醒，既不过分突兀又有足够的辨识度。

## CSS 架构与工程化方式

该项目没有采用 Tailwind CSS、CSS Modules 或任何 CSS-in-JS 方案，也未使用 SCSS/Less 预处理器。整个样式工程由两部分构成：一份全局 CSS 文件（global.css）和每个 Vue 单文件组件内部的 `<style scoped>` 块。global.css 负责三件事——全局 box-sizing 重置、页面底色与溢出控制的基础样式，以及最重要的一环：对 Element Plus 组件库的全站主题覆写。通过 CSS 自定义属性（`--el-color-primary` 及各级 light/dark 变体）和大量针对 `.el-xxx` 类名的直接样式覆盖，将 Element Plus 默认的科技蓝主题整体替换为品牌粉红主题。这种做法的优势在于无须引入 Element Plus 的主题定制工具链，也能实现高度一致的全站组件外观。

每个 Vue 组件通过 `<style scoped>` 管理自身的局部样式，Scoped CSS 的哈希属性确保了组件间的样式隔离。组件内样式写法为纯 CSS，但结合了现代化的布局手段——Flexbox 和 CSS Grid 是绝对主力，几乎未使用传统的浮动布局。样式缩写风格偏向紧凑，属性值常常写得较精炼（如 `flex: 1; min-width: 0` 这种常见于弹性布局中防止溢出的写法），过渡动画统一使用 `.15s` 或 `.2s` 的短时长，保持了交互反馈的灵敏性。

## 顶部导航栏的设计细节

导航栏是整个应用视觉特征最为突出的部分，完全参照了 Bilibili 的顶栏风格。白色背景配极浅投影，内部采用 Flexbox 两端对齐布局，左侧容纳 Logo 和主导航链接，右侧容纳搜索框、上传按钮、通知图标和用户头像。Logo 区域使用“图标 emoji + 品牌名文字”的组合，品牌名文字为 20px 的 800 字重、-0.5px 字间距的粗体粉色文字，视觉冲击力极强。

导航链接的设计是整条顶栏的点睛之笔。每个链接项默认呈现深灰色（#18191c），底部隐藏一条宽度为 0 的粉色指示条。当鼠标悬停或处于当前路由的激活态时，文字变为品牌粉色，底部指示条平滑展开至接近链接文字宽度。这个底部指示条通过 `::after` 伪元素的 `width` 过渡实现，动画曲线为 `ease`，持续 0.2 秒。这种“下划线生长”的交互动效是 Bilibili 的标志性设计语言之一，在本项目中得到了精确的复刻。

搜索框采用浅灰填充底色（#f1f2f3），圆角 8px，在获得焦点时边框变为品牌粉色、背景切换为纯白色，形成聚焦高亮反馈。搜索框右侧紧邻一个 AI 切换标签，默认灰色边框，激活时变为粉红渐变色填充配白色文字，按钮尺寸紧凑（内边距 3px 8px，字号 11px），专门用于切换“关键词搜索”和“AI 自然语言搜索”两种模式。上传按钮是全站最重要的行动号召（CTA）元素，使用品牌粉色填充、白色文字、8px 圆角，悬停时略微放大（scale(1.02)）并加深背景色（#f25d8e），按下时缩回（scale(0.98)），形成了“呼吸感”十足的微观交互。

## 认证页面的居中卡片风格

登录页和注册页采用完全相同的布局模式：整个页面居中显示一个 420 像素宽的白底圆角卡片，上边距通过 `min-height: calc(100vh - 120px)` 配合 Flexbox 居中实现垂直方向上的视觉居中。卡片顶部放置品牌 Logo（emoji 图标 + 粉色粗体文字），下方是表单项，使用 Element Plus 的 `label-position="top"` 让标签显示在输入框上方而非左侧，更符合现代 Web 表单的设计趋势。所有输入框为全宽样式，提交按钮高度固定为 42px，也是全宽。卡片带有极浅的粉色调投影（`0 4px 20px rgba(251,114,153,0.1)`），微妙的品牌暗示。底部链接（忘记密码、注册/登录跳转）使用品牌粉色，悬停时加下划线。

## 首页的多层次信息架构

首页的设计复杂度最高，采用了“Banner 横幅 + 三栏 Grid 布局”的经典信息架构。Banner 区域使用 135 度渐变粉红色背景（从 #fb7299 到 #e8517c 到 #d43d6a），内部叠加两个半透明的白色大圆作为装饰性几何元素，文字为白色，标题字重 800、字号 32px。Banner 的核心交互是一个 AI 搜索输入框搭配两个按钮（AI 搜索和上传模型），输入框右下方是四个半透明圆角标签作为搜索建议，点击即可一键填充搜索词。整个 Banner 的设计风格带有明显的 Web 2.0 时代大横幅遗风，但通过柔和的品牌渐变和简洁的几何装饰使其显得现代而不陈旧。

三栏布局使用 CSS Grid，按照“左侧 200px 分类导航 + 中间弹性内容区 + 右侧 260px 排行侧栏”的比例分配空间。左侧分类菜单采用白底圆角卡片，每个分类项带 emoji 图标和右箭头引导符，悬停时背景变为浅灰（#f1f2f3）、文字变为品牌粉色，过渡平滑。右侧排行列表的数字标签有三级色彩——第一名用品牌粉色填充、第二名用浅粉、第三名用极浅粉，其余用灰色背景，形成清晰的视觉梯度。上传号召横幅（CTA）同样为白底卡片，居中排放火箭 emoji、文案和按钮，给右侧栏一个正向的行为出口。

中间内容区的模型卡片采用四列 Grid 布局（`repeat(4, 1fr)`），每个卡片的封面图区域使用 16:9 的宽高比（通过 `padding-top: 56.25%` 配合绝对定位实现），封面图片在悬停时轻微放大（scale(1.06)），同时浮现半透明黑色遮罩和一个居中白色圆形播放按钮图标。左上角固定显示文件格式角标（如“GLB”），右下角固定显示下载量角标，两者都是半透明黑底白字的样式。卡片信息区包含两行截断的标题文字和一行分类标签与统计数据，整体排版紧凑、信息密度适中，非常适合内容社区的浏览场景。

## 模型详情页的左右分栏设计

详情页是整站最复杂的功能页面，采用了“左侧信息面板（可滚动）+ 右侧 3D 预览与地图（固定）”的双栏布局，通过一个 4px 宽的垂直粉红渐变分隔条区隔。这种布局使得用户在浏览模型元数据时，三维预览始终保持在视野中，不会因滚动而消失，对于以 3D 内容为核心的平台而言是极具用户同理心的设计决策。

左侧信息面板为纯白背景，内容区最大宽度不受限，padding 为 28px 水平 32px 垂直，整体留白充裕。模型名称使用 24px 的深色文字（#303133），上传者信息以头像 + 用户名的 Flexbox 排列显示，描述文字行高设为 1.8 以确保长文本的舒适阅读。操作按钮区使用 Flexbox 包裹，支持自动换行。3D 预览区域背景为深蓝黑色（#1a1a2e），底部有一条半透明黑色状态栏用于显示加载进度、顶点数和三角面数等模型统计信息，状态文字针对不同情况使用不同颜色：加载中为警告橙、加载完成为成功绿、待机为半透明白。

下方的地图面板采用浅蓝色背景（#eaf4ff），无位置信息时显示居中灰色提示文字。整个右侧面板使用 Flexbox 纵向布局，3D 预览区占 3 份弹性空间，地图区占 2 份，中间以 8px 间距分隔。在窄屏（小于 960px）时，双栏布局退化为纵向堆叠，右侧固定高度设为 650px，分隔线也变为水平方向的渐变条。

## 模型卡片组件的设计语言

模型卡片（ModelCard）是全站重复使用频率最高的组件，承载着模型列表的展示任务。卡片整体为白底 8px 圆角，悬停时向上平移 3px 并增加投影深度（从无阴影到 `0 6px 16px rgba(0,0,0,0.08)`），过渡时长 0.2 秒。封面区域高度通过 padding-top 百分比技巧锁定为 16:9，图片使用 `object-fit: cover` 确保不变形填充，占位态显示居中半透明 emoji 图标。

角标系统分为两类：左上角的格式标签和右下角的下载量标签，两者都是 `position: absolute` 定位，半透明黑底（rgba(0,0,0,0.55)），字号分别为 10px 和 11px，bold 或 semibold 字重。hover 时浮现的遮罩层（`opacity: 0 → 1` 过渡）上有一个 44x44 的白色圆形播放按钮，内部播放三角图标为品牌粉色。信息区标题字体大小为 13px、字重 600，使用 `-webkit-line-clamp: 2` 限制为最多显示两行。元数据区（分类标签 + 浏览量和收藏量统计）的字号为 11px，颜色为弱化的灰色（#9499a0），确保标题是卡片中最突出的文字元素。

## 个人主页的社交平台化设计

用户中心（UserCenter/个人主页）是整个前端中设计最丰富、组件最复杂的页面，风格上明显借鉴了国内社交平台（如微博、知乎）的个人主页范式。页面采用“Hero 封面头部 + 滚动吸附的 Tab 导航 + 左 68% 右弹性双栏内容区”的五段式架构，单从这个架构来说，已经具备了一个成熟社交产品个人主页的全部要素。

Hero 封面区高度为 240px，默认使用 135 度紫蓝渐变背景（#667eea 到 #764ba2，与全站粉色主色调形成差异化，暗示个人空间的独立性），覆盖一张半透明深色渐变叠加层。用户头像通过负 margin（margin-top: -48px）上移至封面与信息栏的交界处，外包裹 4px 白色环和投影，从封面中“浮出”的视觉效果非常经典。昵称使用 24px 的 700 字重深色文字，简介为 14px 的次要灰色，统计数字（作品数、下载量、粉丝数）下方跟单位文字，通过深浅对比突出数字本身。

Tab 导航栏使用 `position: sticky; top: 64px` 实现在主顶栏下方吸附，当滚动越过 Hero 区域后自动浮现一条浅投影（通过 IntersectionObserver 动态添加 .is-sticky 类实现），这个细节处理有效提升了多 Tab 页面的导航可达性。Tab 项的设计与顶栏导航链接一脉相承——底部 2px 的品牌粉指示条在激活时显示，悬停时文字变为粉色。主体内容采用 1100px 最大宽度居中、Flexbox 双栏布局，左侧占 68% 弹性宽度用于展示信息流、作品网格或设计随笔时间线，右侧占剩余弹性空间（最少 280px）用于展示侧边栏卡片。

侧边栏卡片模块设计风格统一：白底 10px 圆角，内边距 16px，带极浅投影（`0 1px 4px rgba(0,0,0,0.03)`），标题使用 14px 的 700 字重深色文字，下方有 1px 的浅灰分隔线。卡片内容涵盖个人快捷资料卡（头像 + 昵称 + 简介 + 社交链接）、热门作品 Top5 列表（带数字排名，前三名数字使用品牌粉色）、标签云（字体大小和透明度根据权重动态计算）和最新设计随笔入口。整个侧边栏通过 `position: sticky; top: 120px` 跟随滚动，始终保持在视口的舒适阅读位置。

设计随笔（Blog）区域采用时间线布局，左侧为日期标签（80px 宽、12px 字号、灰色），右侧为标题 + 摘要的纵向排列，标签使用品牌粉的浅色背景搭配粉色文字。精选作品区域则采用横向滚动的卡片列表，卡片固定 220px 宽度，内嵌 130px 高度的封面图，支持触控板和鼠标滚轮的横向滚动，滚动条高度压缩为 6px 的精简样式。

## 管理后台的低调暗色侧栏风格

管理后台与前台主站采用截然不同的视觉策略。侧栏使用深蓝黑色背景（#1a1a2e），菜单文字为浅灰色（#c0c4cc），激活态为品牌粉色（#fb7299），顶部有居中的品牌 Logo 和“3DHub 管理”文字。主内容区为浅灰底色（#f5f5f7），使用 Element Plus 的标准表格组件（带斑马条纹 stripe），表头为深色粗体文字配浅灰底色。整体管理后台设计较为朴素，重点是功能性和数据的清晰展示，而非品牌视觉的延展。

## 上传与编辑表单的步骤式设计

上传模型和编辑模型页面共享一套表单样式体系。页面最大宽度限制为 700px 居中，每个步骤或表单区域包裹在白底 8px 圆角、1px 浅灰边框（#ebeef5）的容器中，内边距 24px。上传页使用 Element Plus 的 Steps 步骤条，步骤标题在激活态使用品牌粉色、完成态使用成功绿色。文件拖拽上传区使用 Element Plus 的默认拖拽组件样式，但边框颜色在悬停时切换为品牌粉色。

建筑信息卡片是一处巧妙的设计亮点：卡片背景使用品牌色的极浅渐变（`linear-gradient(135deg, #fef4f7, #fde8ef)`）、边框为浅粉色（#fcd0df）、圆角 10px，与周围的纯白表单区块形成柔和的色彩对比，暗示这是可选的高级配置区域。卡片内部使用 Flexbox 两端对齐排布标题和开关控件，展开后的详细字段通过一条粉色虚线分隔线与头部区隔，过渡动效使用 Element Plus 内置的 `el-collapse-transition` 组件。

## 搜索页的筛选面板

搜索结果页采用“左侧 180px 筛选面板 + 右侧弹性结果区”的双栏 Flexbox 布局。筛选面板为白底 10px 圆角卡片，分类和文件格式的筛选项使用 Element Plus 的 Radio Group 纵向排列，每项之间有 8px 间距。右侧结果区顶部有结果计数、排序切换（Radio Button 组，最新/最热/下载量），下方为三列 Grid 模型卡片网格。AI 搜索模式下，结果列表上方会展示 AI 生成的搜索摘要（使用 Element Plus 的 info 类型 Alert 组件），当 AI 服务降级时切换为 warning 类型的提示。

## 评论区的简洁对话风格

评论区组件为白底 10px 圆角卡片，标题使用 700 字重深色。每条评论项之间通过 1px 的极浅灰（#f0f0f0）底部分隔线区隔，评论者信息使用 Flexbox 两端对齐——左侧为小头像 + 粗体用户名，右侧为灰色小字时间戳。回复子评论通过 32px 的左缩进和一条虚线顶部分隔（`border-top: 1px dashed #ebeef5`）与主评论形成层级区分。回复输入框在点击“回复”按钮后动态显示，与评论项自然衔接，无突兀感。

## 过渡动画与微观交互模式

全站动画的策略极为克制且高度统一。过渡时长几乎全部集中在 0.15 秒（快速反馈，如按钮颜色变化、链接悬停）和 0.2 秒（略慢的位移动画，如卡片上浮、导航指示条展开）两个档位。transform 相关的动画包括卡片的 `translateY(-2px)` 或 `translateY(-3px)` 上浮、按钮和封面的 `scale` 缩放，均配合 box-shadow 的深度变化来强化“抬起”的立体感。所有过渡都使用 CSS transition 而非 animation/@keyframes，曲线主要使用 `ease` 而非线性，确保动作的自然流畅。预加载骨架屏使用 Element Plus 的 `<el-skeleton>` 组件，切换时无闪烁。

## 响应式设计策略

项目采用渐进的响应式策略，没有针对移动端的单独设计，而是通过针对性的媒体查询断点在窄屏上调整布局。主要的断点层级有三个：1200px、960px 和 540px。1200px 时首页三栏布局的侧栏宽度略微缩小；960px 时三栏退化为单栏、侧栏隐藏、双栏布局（如详情页、个人主页）退化为纵向堆叠；540px 时卡片网格从多列退化为单列。图片和地图使用 `object-fit: cover` 和百分比宽度确保在各种尺寸下的良好适配。滚动条在所有平台上统一为 8px 宽的浅灰色自定义样式。

## 字体与排版约定

全站字体主要依赖系统默认字体栈（通过 Vue 和 Element Plus 的默认设置），未引入 Web Font 或自定义字体文件。标题和重要文字的 `font-weight` 在 600 到 800 之间（Bold 或 Extra Bold），正文为默认 400，整体呈现强烈的粗细对比。字号体系从 Banner 大标题的 32px 到卡片的 13px 到脚注的 10px 跨度合理，同一组件内通常不超过三个字号层级。Logo 文字统一使用 `letter-spacing: -0.5px` 的轻微紧缩，增强品牌标识的紧凑感和辨识度。emoji 表情符号在多处被用作图标替代方案（Logo 的 🏗️、分类的 🏠🏢🏛️ 等），这是中文互联网产品的常见做法，既能降低图标资源成本，又能传达亲切活泼的品牌个性。
